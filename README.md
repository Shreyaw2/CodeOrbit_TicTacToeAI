# Tic-Tac-Toe with Simple AI

## About the Project
This is a Python-based Tic-Tac-Toe game developed as part of the CodeOrbit AI Internship. It allows a human player to play against a computer opponent that uses the Minimax algorithm to make intelligent moves.

## Features
- Interactive 3×3 game board
- Play against the computer
- Computer makes decisions using the Minimax algorithm
- Detects wins, losses, and draws
- Validates player input

## Technologies Used
- Python 3
- Minimax algorithm
- Functions, lists, and conditional statements

## How to Run
1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python tic_tac_toe.py
```

## How to Play
- You play as **X**.
- The computer plays as **O**.
- Enter a number from 1 to 9 to select a position on the board.
- The first player to get three marks in a row, column, or diagonal wins.
- If all positions are filled and nobody wins, the game is a draw.

## Learning Outcomes
Through this project, I practised Python programming, game logic, input validation, and the Minimax algorithm for decision-making.
